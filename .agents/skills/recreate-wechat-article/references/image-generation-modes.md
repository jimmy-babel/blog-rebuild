# 图片生成模式规范

## 参数与默认值

- 图片模式：`--image-mode rebuild|copy|comic`，缩写 `-m`，默认 `copy`。
- `comic` 使用 `--comic-count N` 或 `-n N`，默认 5；只允许和 `article-mode=ori` 搭配。
- 文案模式：`--caption-mode ai|local`，缩写 `-c`，默认 `ai`。
- 品牌人物参考：`--brand on|off`，缩写 `-b`，默认 `on`；关闭时不传品牌人物图，`copy` 仍传来源图。
- `copy + ai` 是默认组合；`rebuild + local` 对应升级前的丰富场景本地排字模式。
- 每张图片必须有独立的 imagegen 请求，避免主体、场景或文字互相污染；所有独立请求必须在同一个并发批次中一次性提交。

## comic

- 只阅读清洗后的原文文字，不读取、不分析、不传入来源图片。
- 将全文拆成 N 个连续叙事节点，每张生成一张完整的 1122×1402 竖向卡片，包含少量中文标题、旁白或对白。
- `brand on` 时所有请求统一使用 `photos/通用1.png`；`brand off` 时不传品牌参考图。
- `comic` 不使用 `--caption-mode`，生成失败使用 `generatedImageLink`，不使用来源图片链接兜底。

## 共同准备

1. 阅读来源图片、相邻正文和重写后的对应章节，确定情绪与品牌人物参考图。
2. 提炼一条与新文章一致、且不复刻原文的目标文案。`ai` 不限制字符数；`local` 删除空白后不得超过 20 个可见字符，标点计入。
3. 使用纵向完整卡片构图。`ai` 画布目标比例为 1122:1402，主体和文案应充分利用画面并减少上下空白；禁止水印、Logo、二维码、署名和广告。
4. 先准备全部任务的提示词和参考图，再使用 `Promise.allSettled` 或等价方式并发调用；不得拆成 2+2 等批次等待。

## 图片模式

### rebuild

- `referenced_image_paths` 只包含所选品牌人物参考图，不包含来源图片。
- 来源图只用于事先提炼抽象主题，不参与生成。
- 重新设计人物动作、场景、道具、背景、镜头与构图；增加有助于表达主题的环境细节、光影和叙事元素。
- 保持品牌人物外貌、发型、饰品和整体3D卡通视觉一致，不复刻来源构图或独特画风。

### copy

- `referenced_image_paths` 按“来源图片、品牌人物参考图”的顺序同时包含两张图。
- 在提示中明确：来源图片负责整张卡片的信息结构、人物动作、关键道具、人物数量、空间关系、色调和排版气质；品牌人物参考图拥有主体身份与3D视觉风格的最高优先级。
- 用品牌人物替换来源主体；辅助人物或动物可以保留其叙事功能，但必须统一为新的品牌视觉体系。
- 允许优化留白和比例，不得像素级复制布局，也不得继承来源图片的原文、独特画风、水印或署名。

## 文案模式

### ai

- 在一次 imagegen 请求中直接生成完整含中文文案的卡片，不调用 `compose_card.py`。
- 每次提示词都明确要求：接近 1122:1402 的纵向比例；整张画布以 `#F7F6F6`（RGB 247,246,246）淡灰白为统一背景；插画和文案紧凑、均衡地占满有效画面；顶部和底部只保留必要安全边距，不得出现大面积空白。
- 不使用 20 字上限、情绪浅色底、分隔线、固定字体、逐字旋转或其他本地模板规则，也不做超长拦截或截断。
- `rebuild + ai` 根据抽象语义自由设计丰富场景与整张卡片；不向 imagegen 传来源图。
- `copy + ai` 跟随来源图整张的信息结构、场景关系、色调和卡片排版，同时替换品牌人物并重写文案。
- 把重写后的目标文案作为需要出现在图中的明确文本提供给模型；具体换行、字体、方向和视觉表现由模型决定。
- 第一张成功返回的图片直接采用。不要 OCR、不要检查错字或漏字、不要重试，也不要因文字瑕疵自动切换到本地模式。
- 将首次返回的原始 PNG 保存为 `raw-cards/image-NNN.png`。全部生图完成后并发调用 `normalize_ai_card.py`，输出 `cards/image-NNN.png`；只有归一后的图片可以供 manifest 引用。

### local

- imagegen 只生成无文字的上半部分插画，禁止汉字、字母、水印、Logo、边框和下方文案区。
- `brand off` 时不传品牌人物图；有 AI 插画即可完成本地排版，不能使用无参考图的回退场景。
- 所有 imagegen 结果结算后，对成功插画一次性并发调用 `compose_card.py`，不得逐张串行等待。脚本生成固定 1080×1440 卡片、满底情绪浅色、1.5 倍艺术字体和稳定的逐字轻微旋转。
- 本地脚本对超过 20 个可见字符的文案直接报错；必须先重新提炼，不得截断。

## 并发与失败

- 全部图片请求只提交一次，并在同一个并发批次中独立结算。任一失败不得取消、延迟或重试其他请求。
- `ai` 成功图片必须是 PNG、精确 1122×1402，边缘背景为 `#F7F6F6`；`local` 成功图片必须是 1080×1440 PNG。不做 OCR 或额外逐图视觉复查。
- imagegen 或本地合成失败时都不再调用 `compose_card.py` 模板兜底。把对应文章块写为 `sourceImageLink`，由 HTML 在原位置显示可点击的原始 HTTPS 图片 URL。
- 原始 URL 不可用时显示“原始图片链接：不可用”并记录告警；不得把来源图片远程嵌入最终 HTML。
