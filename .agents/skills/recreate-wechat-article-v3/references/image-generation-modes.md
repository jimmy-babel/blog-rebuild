# 图片生成模式规范

## 参数与默认值

- 图片模式：`--image-mode rebuild|copy|comic`，缩写 `-m`，默认 `copy`。
- `comic` 使用 `--comic-count N` 或 `-n N`，默认 5；只允许和 `article-mode=ori` 搭配。
- 文案模式：`--caption-mode ai|local`，缩写 `-c`，默认 `ai`。
- 品牌人物参考：`--brand on|off`，缩写 `-b`，默认 `on`；关闭时不传品牌人物图，`copy` 仍传来源图。
- brand on 时按 `characters` 选择一张或多张角色参考图：角色只能是 `girl`、`girl-baby`、`girl-old`、`boy`、`boy-baby` 或 `boy-old`；每个角色计划还要包含 `ageGroup=child|adult|elder|unknown` 和简短 `ageEvidence`。普通单主角只选女性年龄角色，男女组合按男角色+女角色，年龄不明的主角固定使用 `girl.png`。
- `copy + ai` 是默认组合；`rebuild + local` 对应升级前的丰富场景本地排字模式。
- 每张图片必须有独立的 imagegen 请求，避免主体、场景或文字互相污染；所有独立请求必须在同一个并发批次中一次性提交。

## comic

- 只阅读清洗后的原文文字，不读取、不分析、不传入来源图片。
- 将全文拆成 N 个连续叙事节点，每张生成一张完整的 1080×1350 竖向卡片，包含少量中文标题、旁白或对白。
- 每个叙事节点单独判断 `sceneType`、`characters` 和每个角色的年龄分组；普通单主角使用女性年龄角色，男女组合使用对应年龄的男角色+女角色，夫妻/情侣+孩子追加 baby 角色；`brand off` 时不传品牌参考图。父母、夫妻和青年/成年人使用基础 `girl/boy`，只有明确爷爷奶奶辈、祖父母或老年身份才使用 `old`。
- `comic` 不使用 `--caption-mode`，生成失败使用 `generatedImageLink`，不使用来源图片链接兜底。
- `comic` 每个叙事节点按角色列表传入对应参考图；若节点包含其他人物，必须分别描述其不同外观，不得把主角参考图复制给其他人物。

## 共同准备

1. 阅读来源图片、相邻正文和重写后的对应章节，先确定场景类型、每个人的性别/年龄角色和独立的情绪字段。角色用于品牌人物参考图，情绪只用于 local 模式的配色和文字排版。
2. 记录 `sceneCharacterCount`、`secondaryCharacterNotes` 和 `allowIntentionalDuplicate`。缺失人物数量按 1 处理；缺失或非法的 `allowIntentionalDuplicate` 按 `false` 处理。只有来源文字或画面明确表达双胞胎、分身或镜像时才允许 `true`。
3. 提炼一条与新文章一致、且不复刻原文的目标文案。`ai` 不限制字符数；`local` 删除空白后不得超过 20 个可见字符，标点计入。
4. 使用纵向完整卡片构图。`ai` 画布目标比例为 1080:1350，主体和文案应充分利用画面并减少上下空白；最终图片禁止出现来源图中的水印、Logo、二维码、署名和广告元素。来源图角落的二维码或署名只作为应忽略的来源水印，不构成删除整张图片的理由。
5. 先准备全部任务的提示词和参考图，再使用 `Promise.allSettled` 或等价方式并发调用；不得拆成 2+2 等批次等待。

### 多人物隔离规则

- `sceneType` 先判断为 `single`、`mixed_pair`、`romantic_pair`、`family_trio` 或 `other_group`；`characters` 按主角在前、次要人物在后记录角色与用途。
- 明确夫妻/情侣、普通一男一女同框时使用男角色+女角色；夫妻/情侣+孩子追加 baby 角色；年龄按每个人分别判断，年龄不明用青年角色，孩子性别不明用 `girl-baby`。
- 非男女组合继续判断喜/乐/怒/哀/通用，但品牌参考改用 `girl`、`girl-baby` 或 `girl-old`，年龄不明使用 `girl`。
- `character` 是兼容字段，表示主角；品牌角色参考图只约束对应角色，不是所有人物的通用模板。`parent/mother/father` 关系优先归为 `adult`，`grandparent/grandmother/grandfather` 归为 `elder`，不能仅凭白发、皱纹、服装或坐姿把父母标成 `old`。
- 多人画面中，次要人物必须与主角及彼此明显区分，至少在脸型、发型/发色、年龄/体型、服装/配饰或姿态中的多个维度不同。
- 来源图只提供人物数量、动作、关键道具和空间关系，不提供可复制的脸部身份、发型、服装或独特外观。
- 除非明确是双胞胎、分身或镜像，否则禁止同一张图出现两个外貌近乎相同的人物；每张角色参考图只对应一个计划角色。

## 图片模式

### rebuild

- `referenced_image_paths` 只包含 `characters` 中按角色映射排列的参考图，不包含来源图片；年龄不明的角色在多人组合中按对应性别使用青年角色，主角年龄不明时按 `girl` 处理。
- 来源图只用于事先提炼抽象主题，不参与生成。
- 重新设计人物动作、场景、道具、背景、镜头与构图；增加有助于表达主题的环境细节、光影和叙事元素。
- 保持品牌人物外貌、发型、饰品和整体3D卡通视觉一致，不复刻来源构图或独特画风。
- 多人物时按 `characters` 为每个固定角色使用对应参考图；所有未使用参考图的辅助人物必须重新设计为明显不同的角色。

### copy

- `referenced_image_paths` 按“来源图片、角色参考图列表”的顺序传入；普通场景为来源图+一个女性年龄角色，男女组合为来源图+男角色+女角色，夫妻/情侣+孩子再追加 baby 角色。
- 在提示中明确：来源图片负责整张卡片的信息结构、人物动作、关键道具、人物数量、空间关系、色调和排版气质；角色参考图拥有主体身份与 3D 视觉风格的最高优先级。
- 在提示中明确每张角色参考图对应的 `role`；角色图只定义对应人物的身份与 3D 视觉风格，次要人物不得复制其他角色的脸型、发型、服装和配饰。
- 用品牌人物替换来源主体；辅助人物或动物可以保留其叙事功能，但必须统一为新的品牌视觉体系。
- 允许优化留白和比例，不得像素级复制布局，也不得继承来源图片的原文、独特画风、水印、署名、二维码或广告角标；即使来源图与正文关系不明确，也应保留其信息结构并完成重制。

## 文案模式

### ai

- 在一次 imagegen 请求中直接生成完整含中文文案的卡片，不调用 `compose_card.py`。
- 每次提示词都明确要求：接近 1080:1350 的纵向比例；整张画布以 `#F7F6F6`（RGB 247,246,246）淡灰白为统一背景；插画和文案紧凑、均衡地占满有效画面；顶部和底部只保留必要安全边距，不得出现大面积空白。
- 不使用 20 字上限、情绪浅色底、分隔线、固定字体、逐字旋转或其他本地模板规则，也不做超长拦截或截断。
- `rebuild + ai` 根据抽象语义自由设计丰富场景与整张卡片；不向 imagegen 传来源图。
- `copy + ai` 跟随来源图整张的信息结构、场景关系、色调和卡片排版，同时替换品牌人物并重写文案。
- 把重写后的目标文案作为需要出现在图中的明确文本提供给模型；具体换行、字体、方向和视觉表现由模型决定。
- 第一张成功返回的图片直接采用。不要 OCR、不要检查错字或漏字、不要重试，也不要因文字瑕疵自动切换到本地模式。
- 将首次返回的原始 PNG 保存为 `raw-cards/image-NNN.png`。全部生图完成后并发调用 `normalize_ai_card.py`，输出 `cards/image-NNN.png`；只有归一后的图片可以供 manifest 引用。

### local

- imagegen 只生成无文字的上半部分插画，禁止汉字、字母、水印、Logo、二维码、来源署名、广告角标、边框和下方文案区；来源图角落的二维码或水印只需忽略，不得因此删除该图片任务。
- `brand off` 时不传角色参考图；有 AI 插画即可完成本地排版，不能使用无参考图的回退场景。
- 所有 imagegen 结果结算后，对成功插画一次性并发调用 `compose_card.py`，不得逐张串行等待。脚本生成固定 1080×1350 卡片、满底情绪浅色、1.5 倍艺术字体和稳定的逐字轻微旋转。
- 本地脚本对超过 20 个可见字符的文案直接报错；必须先重新提炼，不得截断。

## 并发与失败

- 全部图片请求只提交一次，并在同一个并发批次中独立结算。任一失败不得取消、延迟或重试其他请求。
- `ai`、`comic` 和 `local` 成功图片必须是 PNG、精确 1080×1350；`ai` 与 `comic` 的边缘背景为 `#F7F6F6`。不做 OCR 或额外逐图视觉复查。
- imagegen 或本地合成失败时都不再调用 `compose_card.py` 模板兜底。把对应文章块写为 `sourceImageLink`，由 HTML 在原位置显示可点击的原始 HTTPS 图片 URL。
- 原始 URL 不可用时显示“原始图片链接：不可用”并记录告警；不得把来源图片远程嵌入最终 HTML。
